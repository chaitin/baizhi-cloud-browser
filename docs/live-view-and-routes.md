# 观看、人工交接与网络线路

这些能力由百智云云浏览器的 HTTP／MCP 提供。已有 Agent 与页面客户端可继续使用，观看不要求进入管理后台。实际接口与限制以[线上接入参考](https://capybrowser.app.baizhi.cloud/docs/browser-reference.md)为准。

## 先看进展，不必先接管

在原来的 Agent 对话中说：

```text
让我看看当前浏览器页面，先只看，不接管。
```

Agent 为当前已就绪的运行生成真实观看链接后，发给你直接打开。观看不会抢走 Agent 的控制，也不会额外创建一台浏览器。不要把一次性 CDP 控制地址当作观看链接。

开发者可使用以下入口；HTTP 路径均相对 `/openapi/v1`：

| 动作 | HTTP | MCP |
| --- | --- | --- |
| 为已有运行生成观看链接 | `POST /browser/sessions/:id/view-links` | `browser_create_view_link` |
| 撤销一条观看链接 | `DELETE /browser/sessions/:id/view-links/:grant_id` | `browser_revoke_view_link` |

默认使用 `scope=view`。只有用户明确希望自己操作时，才签发 `scope=view_takeover`。取得实际响应中的 `page_url` 后再发给用户，不自行拼接 URL。

## 需要时，轮流操作同一页面

1. 明确告诉 Agent 你需要亲自操作，让它提供可接管入口。
2. 在观看页点击“我要操作”，核对页面并确认接管；Agent 暂停网页操作。
3. 完成登录或确认后，点击“完成并交还 Agent”，把页面给出的回复发回原对话。
4. Agent 接回原来的运行，重新观察页面后继续。

有效且允许接管的链接，在同一窗口中可以“再次接管”；每一轮都要明确确认。再次操作不延长授权。只读、撤销、过期或运行已结束时不能再次接管。

Agent 调用方应在人工操作期间保留原运行，暂停页面写操作和自动抢回控制，不能把这次 CDP 断开直接作为自动结束的理由。交还后申请原运行的新控制地址，先观察再继续，不重放结果未知的操作。服务不会代替所有第三方 Agent 自动安排这段对话。

观看链接是临时访问凭证，由首次领取的浏览器使用，不要公开转发。关闭观看页不等于交还，也不等于结束浏览器。观看、等待与人工操作期间仍计运行费。

## 为本次任务选择可用线路

需要更换网络出口时，可让 Agent 在创建浏览器运行时选择平台提供的指定线路，无需自行配置。

在原对话中说：

```text
这次用指定线路。先查当前可用目录和价格，只为本次任务选择，不保存长期偏好。
```

Agent 先用 `GET /openapi/v1/browser/egress-lines` 或 MCP `browser_list_egress_lines` 查询当前身份可见的目录，再将选定的 `egress_line_id` 放入本次创建请求。未指定时沿用已有偏好或默认出口；旧用户无需新增参数。

只有明确要求“以后都用”时，才按正式参考保存 Profile 偏好。目录如果只有 `default`，就没有其他线路可选；线路不可用时应报告失败，不悄悄改走默认出口。

**指定线路在当前体验期免线路附加费，浏览器启动与运行仍正常计费。** `egress.additional_fee_centipoints=0` 不表示浏览器整单免费。Agent 应查询当前目录和价格；体验期后的线路价格另行公布，收费前会明确告知。

指定线路不等于固定或独立公网 IP，也不能保证某个网站放行或自动通过验证。

## 与现有客户端的关系

观看和线路选择是服务能力，不表示 agent-browser v0.1.3、现有 browser-use 示例或其他第三方客户端已原生提供对应新命令。需要时由运行管理代码或已配置的 MCP 使用这些接口，并始终保持同一个任务与运行的对应关系。
